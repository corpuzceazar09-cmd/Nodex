# NODEX bedroom update

- Fixed bed proximity detection using distance to object bounds, rather than its center.
- Added E/Enter/Space/Escape wake-up support.
- Bed wake-up now places the player next to the bed.
- Changed bedroom canvas to compose a dedicated room background with furniture sprites.
- Added original wood-plank/room background for Classic and NODEX themes.
- Preserved the tutorial NPC, player data, computer boot and learning modules.

The generated concept illustration is a visual reference, **not** a collision-aware tileset. This version uses a separately generated pixel background plus existing individual furniture sprites. Further asset refinement and four-directional character animation remain to be done.
